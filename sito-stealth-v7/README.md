# Stealth homepage v7

Static production candidate for GitHub Pages.

- `index.html`: semantic, complete no-JS fallback.
- `styles.css`: visual system, responsive layout, editorial work objects.
- `app.js`: content loader + dependency-free scroll motion.
- `content.json`: runtime-editable copy.
- `design-contract.json`: development-only design/motion contract.

The desktop case chapter is driven by vertical scroll and uses a pinned horizontal track. Mobile uses a natural vertical sequence and never inherits horizontal pinning.
