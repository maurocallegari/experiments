# Stealth homepage V8

Rebuild based on the user's latest direction, which supersedes older storyboard details where they conflict.

## Files
- `index.html`: semantic fallback content and visual objects
- `styles.css`: imports split responsive art direction
- `app.js`: scroll-linked reversible motion + content loader
- `content.json`: editable production copy
- `design-contract.json`: implementation contract for future AI changes

## Key difference from V7
V8 does not start from the older calm/ordered hero storyboard. It starts from a crowded real-work scene, converges that chaos during scroll, and uses one overlaid pinned stage for the four friction cases instead of a visible horizontal carousel/track.
